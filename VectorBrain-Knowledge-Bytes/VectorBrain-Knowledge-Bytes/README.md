# VectorBrain — Knowledge Bytes

This folder contains small, progressive knowledge-byte documents for the VectorBrain project.

## Source and scope

The structure follows the supplied Knowledge Bytes reference:
- one concept/responsibility per byte
- progressive ordering from purpose → structure → details → edge cases
- plain-language explanation first
- focused code/config snippets
- mechanics + intent
- why the piece matters
- a final "PUTTING IT TOGETHER" section

The reference also recommends calibrating the bytes to the project's language/context and keeping each byte short enough to read quickly. See the supplied prompt for the exact rules. 

## Project scope covered

VectorBrain is documented as a multi-document research/study assistant built around:
- Vue.js 3 frontend
- FastAPI backend
- PostgreSQL + pgvector
- Docling document processing
- Groq API
- semantic/vector search
- multi-document RAG
- source-aware answers
